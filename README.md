# Interval Camera
1. Создайте пустой репозиторий на GitHub и загрузите в него ВСЁ содержимое этой папки (включая скрытую папку .github).
2. Откройте вкладку Actions -> Build APK -> дождитесь зелёной галочки (2-5 минут).
3. В конце страницы запуска, раздел Artifacts: скачайте IntervalCamera-debug-apk (zip), внутри app-debug.apk.
4. Перенесите APK на телефон и установите (разрешите установку из неизвестных источников).
